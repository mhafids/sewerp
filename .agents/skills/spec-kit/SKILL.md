# Spec-Kit (Spec-Driven Development)

Spec-Kit brings GitHub's Spec-Driven Development methodology to your AI pair programming workflow. It emphasizes locking down user scenarios, requirements, and system boundaries before writing code.

## Key Templates Available in This Skill:
- `spec-template.md`: Feature specification outline with prioritized user stories (P1/P2/P3), independent testability requirements, and acceptance scenarios.
- `plan-template.md`: Implementation architecture plan with technical context, project structure, and constitution checks.
- `tasks-template.md`: Dependency-ordered task lists with phase milestones.
- `checklist-template.md`: Verification and quality gates.

## Usage Guideline
When executing SDD:
1. Define the specification using `spec-template.md`.
2. Verify against core project constitution and tech stack constraints (`plan-template.md`).
3. Break the approved spec into ordered development tasks.
